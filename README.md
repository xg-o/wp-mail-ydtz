# wp-mail-ydtz
一个wp（WordPress）邮件阅读通知插件。
# 原理简述
1. 发送邮件时，在 HTML 正文末尾插入一张 1×1 透明图片（追踪像素）。
2. 图片 URL 指向本站：  https://本站/track/<token>.gif
3. 收件人打开邮件、客户端加载图片时，请求回到本站 ->在那一刻拿到对方的真实 IP、地理位置、设备、系统、浏览器、时间。
4. 请求链路：邮件客户端 → GET /track/<token>.gif→ 记录打开事件 → 写入存储 → 后台"打开记录"里展示 / 实时通知。
5. 链接点击追踪（可选）：正文 <a> 改写为 /go/<id>，点击时记录并 302 跳转。
   完
注意："打开" = "至少加载过一次图片"，不等于"认真读完"。
